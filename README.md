
# Legendary System

Legendary System is an independent Linux
distribution currently in development.

## Vision

To create a beautiful, peaceful, and cohesive
desktop operating system that makes everyday
computing feel comfortable and effortless.

## Goals

- Build an independent Linux distribution
- Develop reproducible builds from source
- Create an original desktop experience
- Support internet access and applications
- Prioritize beauty, simplicity, and freedom

## Development

Status: Early development

Our first milestone is to build and boot
a minimal Linux system from source.

We are using Linux From Scratch as a
learning reference, with the goal of
developing independent build infrastructure.
